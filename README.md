A realistic, browser-based replica of the Windows 11 "Working on updates" screen. Perfect for a harmless office or classroom prank.

---

## 🚀 Features
* **Customizable Settings:** Adjust the total duration and the starting percentage.
* **Input Locking:** Option to disable specific keys and/or mouse inputs to make it more convincing.
* **Fully Browser-Based:** No installation required—runs entirely in the browser.
* **High Realism:** Replicates the fonts, animations, and layout of a real Windows 11 update.

## 🛠️ How to Use
1. Head over to the [GitHub Pages site](https://ferlaty.github.io/fake-windows-update/).
2. Configure your preferred duration, start percentage, and key-lock settings.
3. Click **Start Fake Update**.

> ⚠️ **How to Exit:** If the `ESC` key doesn't work, press and hold it down, or use `F11` (or `Fn + F11`) to exit full-screen mode and close the tab.
